# Mirage — Linux Identity Virtualization & Audit Platform

Mirage lets a user audit and, where technically honest, project a consistent virtual identity (location, time, locale, network, hardware IDs, browser fingerprint) to applications running in an isolated sandbox, without altering the host system. It exists for: personal privacy, security/privacy research, and testing how software behaves under different locale/geo/network conditions.

Mirage is explicitly NOT for: evading platform bans, creating multiple accounts on a single service (sybil/multi-accounting), defeating fraud-detection or KYC systems, circumventing regional pricing/licensing restrictions, or impersonating a specific real third party. Do not build features whose primary value is defeating a third-party service's anti-abuse system; build features whose primary value is the user understanding and controlling their own observable signals.
